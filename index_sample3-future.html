03 / FUTURE & CONTACT

영역을 넘어 핵심 시스템을 책임지는 개발자로

작은 기능 수정부터 시스템 설계와 통합까지, 데이터 흐름과 예외 상황을 함께 살피며 변경에 강한 구조를 만들겠습니다.

MY PRINCIPLE플레이어가 의도한 행동이 오류 없이 게임의 결과로 이어지도록, 보이지 않는 곳에서 게임의 안정성을 책임지겠습니다.

기술 스택과 근거

기술을 사용한 경험과
문제를 해결한 맥락입니다.

C++ / WinSock / TCP

TwoFacedPoker의 멀티스레드 게임 서버, 패킷 framing, 송신 큐와 연결 lifecycle을 구현했습니다.

C# / Unity

PixelKov와 IDLEAdventure에서 게임 시스템, 아이템·인벤토리, 저장·복원 기능을 개발했습니다.

Java / Spring / Keycloak

TmaxGPMS에서 OAuth2/JWT 인증, 권한 매핑, Script 정책 API를 개발했습니다.

Python / Linux PAM

Python Agent와 Linux PAM을 연동해 WAS 인증부터 OS 로그인까지 이어지는 흐름을 구현했습니다.

Docker / Shell

인증 서버 배포 자동화와 Master–Slave DB 동기화, 재시도·예외 처리 자동화를 구성했습니다.

협업 / Git

팀장으로서 일정과 작업 범위를 조율하고, Git 기반으로 팀의 개발 흐름을 관리했습니다.

협업 방식

자율성을 존중하면서도
끝까지 책임지는 방식입니다.

조율과 책임

데일리 스크럼으로 진행 상황을 확인하고 작업이 겹칠 가능성이 있는 부분을 미리 공유했습니다. 일정이 지연될 때는 업무를 재분배하고 씬 연결과 시스템 통합을 직접 맡았습니다.

기술 부채 관리

일정이 임박하면 목표 달성을 위해 업무 범위를 넓히는 경향이 있습니다. 현재는 구현 전에 필수 기능과 개선 작업을 분리하고, 위험 요소와 리팩토링 일정을 미리 계획하려고 노력합니다.

입사 후 포부

프로젝트에 안정적으로 적응하고
핵심 시스템을 독립적으로 개선하겠습니다.

기능의 시작부터 실제 게임 반영까지 책임지겠습니다.

입사 초기에는 프로젝트의 코드 구조와 게임 플레이 흐름, 데이터가 클라이언트와 서버 사이에서 전달되는 과정을 빠르게 파악하겠습니다. 기존 팀의 규칙과 프로세스를 준수하며 작은 기능 수정과 버그 재현·해결부터 정확하게 수행하겠습니다.

이후에는 클라이언트, 서버, 시스템 통합 등 필요한 업무를 맡아 기능의 시작부터 실제 게임 반영까지 책임지겠습니다. 장기적으로는 프로젝트의 핵심 시스템을 독립적으로 설계하고 개선하며, 해결한 문제와 설계 의도를 팀과 공유하겠습니다.
