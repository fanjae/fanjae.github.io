Problem Solving

문제를 구조로 해결하다

동작하는 코드에서 멈추지 않고 통신의 신뢰성과 데이터 일관성까지 살폈습니다.

01 / NETWORK SERVER

패킷 경계와 이벤트 순서를 보장

TCP 스트림에서 메시지 경계가 보장되지 않는 문제를 확인하고 4바이트 길이 헤더와 RecvAll()·SendAll()을 적용했습니다. 연결별 송신 큐와 Sender Thread로 여러 Worker Thread의 송신 순서도 통제했습니다.

02 / SAVE SYSTEM

게임 상태의 일관성을 보장

ISaveDataWriter로 저장 책임을 시스템별로 분리하고, GameSaveDataSnapshot을 백그라운드에서 직렬화했습니다. 중첩 컬렉션까지 복사해 저장 중 원본 변경이 사본에 영향을 주지 않도록 했습니다.

Collaboration · Direction

핵심 시스템을
책임지는 프로그래머

팀원의 자율성을 존중하면서도 전체 진행 상황을 파악하고 필요한 순간에 조율합니다. IDLEAdventure에서는 데일리 스크럼으로 작업 충돌을 줄이고, 일정이 지연될 때 씬 연결과 시스템 통합을 맡아 핵심 기능의 완성을 도왔습니다.

입사 후에는 프로젝트의 코드 구조와 게임 플레이 흐름, 클라이언트와 서버 사이의 데이터 전달 과정을 빠르게 파악하겠습니다. 작은 기능 수정과 버그 재현·해결부터 정확히 수행하고, 이후에는 기능의 시작부터 실제 게임 반영까지 책임지겠습니다.

플레이어가 의도한 행동이 오류 없이 게임의 결과로 이어지도록, 보이지 않는 곳에서 게임의 안정성을 책임지겠습니다.
